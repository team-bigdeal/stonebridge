# 돌다리 (팀 빅딜)

사람이 여러 사이트를 돌아다니며 견적을 내 보는 번거로움을 대신하는 **견적 에이전트** 데스크톱 앱.
브라우저 3개가 동시에 업체를 찾아 견적을 모으고, 웹·메일·파일로 제각각인 견적을 **하나의 견적서 양식으로 통일**해 보여 줍니다.

## 실행

```bash
npm install
npm run dev
```

처음 실행하면 설정 창이 열립니다. Anthropic API 키를 넣으면 바로 쓸 수 있습니다 (이 컴퓨터의 `.env`에만, 권한 600으로 저장).
설정 → 메일에서 **Google 계정으로 연결**하면 메일 카드의 "승인하고 보내기"로 내 Gmail에서 업체에 메일을 보내고 업체 회신을 자동으로 읽습니다 ([메일](#메일-google-계정-연결)). 앱 비밀번호로도 연결할 수 있고, 둘 다 없으면 "메일 앱으로 열기" + "회신 붙여넣기".

## 메일 (Google 계정 연결)

견적을 메일로만 주는 업체에는 돌다리가 견적 요청 메일을 써 두고, 사용자가 "승인하고 보내기"를 누르면 연결한 Google 계정으로 보냅니다(SMTP). 업체 회신은 같은 계정의 받은편지함에서 제목 태그 `[돌다리#B-xxxxxx]`로 찾아(IMAP) 견적서 양식으로 정리합니다.

- 연결: 설정 → 메일 → "Google 계정으로 연결" → 기본 브라우저에서 로그인·메일 권한 동의 → 앱으로 돌아옴. 돌다리는 Google 비밀번호를 보지 않습니다.
- 방식: OAuth 2.0 데스크톱 앱 방식(시스템 브라우저 + `127.0.0.1` 임시 주소 + PKCE). SMTP·IMAP 로그인은 XOAUTH2이고, 권한은 `https://mail.google.com/`(SMTP·IMAP에 필요)입니다.
- 보관: 갱신 토큰은 OS 키체인으로 암호화해 사용자 데이터 폴더의 `google-account.json`에만 두고 화면(renderer)에는 넘기지 않습니다. "연결 해제"를 누르면 지우고 Google에 권한 철회도 요청합니다.

처음 한 번, 팀에서 Google Cloud 콘솔에 OAuth 클라이언트를 만듭니다.

1. 프로젝트를 만들고 **Gmail API**를 사용 설정합니다.
2. OAuth 동의 화면(Google 인증 플랫폼): 대상 "외부", 게시 상태 "테스트", **테스트 사용자**에 쓸 Gmail 주소를 넣습니다.
3. 데이터 액세스(범위)에 `https://mail.google.com/`을 추가합니다.
4. 클라이언트 만들기 → 유형 **데스크톱 앱** → 받은 클라이언트 ID·보안 비밀을 앱 설정 창(메일 → Google OAuth 클라이언트)에 넣거나 `.env`의 `GOOGLE_CLIENT_ID`·`GOOGLE_CLIENT_SECRET`에 넣습니다. 값은 팀 비밀번호 관리자로 공유합니다 (git·채팅에 붙여 넣지 않기).

테스트 상태의 앱은 "Google에서 확인하지 않은 앱" 화면이 뜨면 "계속"을 누르면 되고, 7일마다 다시 연결해야 합니다 (만료되면 앱이 다시 연결하라고 알려 줌).

### 시연용 메일 (`.test` 주소)

목업 업체의 메일 주소는 모두 `.test`(실제로는 배달되지 않는 예약 도메인)입니다. 이 주소로 "승인하고 보내기"를 누르면 **바로** 업체 이름으로 된 **시연용 회신이 견적서 PDF를 붙여** 옵니다.

- 채팅에 "회신 첨부 견적서" 카드가 뜹니다: "회신 첨부 견적서를 읽고 있어요" → 읽은 금액(제품가·추가 비용·배송비·납기)과 총액·순위, 아래에 PDF 미리보기.
- 읽은 견적은 다른 업체와 같은 기준으로 비교표·순위·추천·통합 견적서에 들어갑니다. 업체 견적서의 "받은 원본"에는 "메일 회신"과 "견적서 PDF"가 따로 보입니다.
- Google 계정(또는 앱 비밀번호)이 연결돼 있으면: 메일을 실제로 보내되 배달은 내 메일함으로 받고(보낸편지함에는 업체 주소로 남음), 같은 시연용 회신(PDF 첨부)이 받은편지함에도 들어갑니다. 앱은 받은편지함을 기다리지 않고 회신을 바로 반영합니다.
- 연결이 없거나 계정으로 보내지 못하면(토큰 만료 등): 실제로 보내지 않고 회신만 흉내 냅니다 (못 보낸 사유는 알림으로 보여 줌).
- `quote@label-gongbang.test` 말고 다른 `.test` 주소(예: `quote@hanaprint.test`)로 보내면, 회신 견적의 총액이 그때까지 찾은 다른 업체 최저 총액보다 약 10% 싸게 옵니다 (메일로 물어본 업체가 1위로 올라오는 장면). 아직 비교할 업체가 없으면 예산의 45% 정도로 옵니다.
- 시연 모드: ⚙️ 설정 → 메일 → "시연용 받는 사람"에 `.test` 주소(예: `quote@hanaprint.test`)를 넣어 두면 업체 메일 초안의 받는 사람이 모두 그 주소로 바뀝니다 (`.env`의 `DEMO_MAIL_TO`). 비우고 저장하면 꺼집니다.
- 시연용 회신과 견적서 PDF 끝에는 "돌다리 시연용 자동 회신"이라고 적혀 있습니다. 실제 업체 주소에는 이 동작이 일어나지 않습니다.

시연 순서 (목업 업체 `npm run mock`을 켠 뒤):

1. 채팅에 입력: `원형 방수 스티커 3000장 견적 비교해 줘. 지름 50mm 유광, 예산 20만원, 10일 안에, 대구 수성구로 택배, 설치·A/S는 필요 없어요. 업체: http://localhost:4101 http://localhost:4102 http://localhost:4106`
2. "이 조건으로 찾기 시작" → 4102 라벨공방은 가격이 없어 "라벨공방에 보낼 견적 요청 메일" 카드(받는 사람 `quote@label-gongbang.test`)가 뜹니다.
3. "승인하고 보내기" → 바로 라벨공방 회신과 첨부 견적서 PDF를 읽는 카드가 뜹니다.
4. 라벨공방은 표시가(59,400원)가 가장 싸서 잠깐 1위가 되지만, 칼선 제작비 8,800원과 배송비 4,000원이 더해져 총액 72,200원으로 2위로 내려갑니다 (1위 스티커팩토리 68,500원, 3위 스티커프린트 75,600원).

## 시연용 빌드 (macOS, Apple Silicon)

```bash
npm run dist
```

- `apps/desktop/dist/`에 `stonebridge-<버전>-arm64.dmg`와 `.zip`이 생긴다. dmg를 열어 StoneBridge를 응용 프로그램으로 옮기면 된다.
- 서명·공증을 하지 않은(ad-hoc) 빌드라 다른 맥에서 처음 열 때 "확인되지 않은 개발자" 경고가 뜨면, 앱을 우클릭 → 열기.
- 빌드한 앱은 API 키를 레포 `.env`가 아니라 사용자 데이터 폴더(`~/Library/Application Support/doldari-desktop/.env`)에서 읽는다. 처음 한 번 ⚙️ 설정에 키를 넣는다. 견적 히스토리는 개발용 앱과 같이 쓴다.
- 앱은 화면을 꽉 채워 열리고, 오른쪽 위 ⛶ 버튼으로 전체 화면을 켜고 끈다.

## 브라우저

에이전트는 앱 안 내장 브라우저(Electron WebContentsView, CDP로 조작)만 씁니다. 별도 브라우저 설치는 필요 없습니다.

- 브라우저 화면이 카드 자리에 그대로 뜹니다. 사용자가 직접 보고 쓰는 브라우저와 같은 방식이라, 화면을 바로 클릭·입력할 수 있습니다. 카드가 화면 밖으로 스크롤되면 마지막 화면 이미지가 대신 보입니다.
- **미리 로그인**: 설정(⚙️) → 브라우저에서 사이트 주소를 넣고 "로그인 창 열기"를 누르면 같은 세션의 창이 열립니다. 직접 로그인해 두면 내장 브라우저가 그 로그인 상태를 씁니다 (돌다리는 비밀번호를 보지 않음).
- **견적서 신청자명**: "견적서 출력" 창이 신청자명(이름·회사명·상호)만 묻고 "다음/확인"을 눌러야 견적서를 보여 주면, 에이전트가 설정(⚙️) → 견적서의 신청자명(비우면 "돌다리 사용자")을 넣고 눌러 나온 견적서를 PDF 원본으로 받습니다. 연락처·이메일·주소·약관 동의 등 다른 칸이 하나라도 있으면 넣지 않습니다. `.env` 항목은 `QUOTE_REQUESTER_NAME=` (빈 값이면 기본값).

에이전트 커서는 페이지에 스크립트를 넣지 않고 앱 레이어에 그립니다. 차단 회피 기법(자동화 흔적 숨기기, CAPTCHA 풀이, 프록시 등)은 쓰지 않습니다.

### 차단 화면 → 사용자에게 넘기기

페이지 이동·클릭 뒤 HTTP 403/418/429, 보안 확인(CAPTCHA) 문구, 원하지 않은 로그인 리다이렉트가 보이면 에이전트가 **바로 멈추고** 카드에 노란 안내를 띄웁니다.
- **해결했어요, 계속**: 사용자가 화면에서 직접 해결한 뒤 누르면 같은 단계부터 이어서 진행
- **건너뛰기**: 그 업체를 빼고 다음 업체를 찾음 (검색 페이지가 막혔으면 다음 검색 엔진으로). 시도할 업체가 없으면 메일/파일 대안 또는 URL 입력 안내

### 업체 URL을 직접 주기

첫 요청에 업체 URL을 넣으면 검색 없이 그 업체들(최대 3곳)에서 바로 견적을 받습니다.

## 테스트용 목업 업체

```bash
npm run mock
```

- `http://localhost:4101` 가격 공개 + 수량 옵션에 따라 금액 계산
- `http://localhost:4102` 가격 비공개, 메일 문의만 (`quote@label-gongbang.test`로 보내면 시연용 회신이 옴)
- `http://localhost:4103` 첫 방문은 HTTP 418 보안 확인 화면 → "확인"을 누르면 정상 (계속 테스트)
- `http://localhost:4103/always` 항상 418 (건너뛰기 테스트)
- `http://localhost:4104` 가격은 보이지만 배송비·제작 기간은 닫힌 "배송/교환" 탭 안에만 있음 (숨은 정보 탐색 테스트)
- `http://localhost:4105` 1시트(24개) 600원 — 1개 가격으로 잘못 읽으면 다른 업체보다 수십 배 비싸짐 (수량 재확인 테스트)
- `http://localhost:4106` 화면엔 가격이 없고 "견적서 다운로드"를 누르면 가견적서 PDF가 내려옴 (PDF 받기·분석 테스트)
- `http://localhost:4108` "견적서 출력"을 누르면 신청자명만 묻는 창 → "다음" → 인쇄용 견적서 (신청자명 양식 테스트). `/popup`은 같은 양식을 팝업 창으로, `/contact`는 연락처·이메일·동의까지 묻는 양식 (넣지 않고 멈춰야 함)

예: "원형 방수 스티커 3000장 견적 비교해 줘. 지름 50mm 유광, 예산 20만원, 10일 안에, 대구 수성구로 택배, 설치·A/S는 필요 없어요. 업체: http://localhost:4101 http://localhost:4102 http://localhost:4103"

## 흐름 (대화 하나로 이어짐)

1. **요구 조건** — 품목을 말하면 수량·예산·납기·설치·A/S·지역을 짧게 묻습니다.
2. **브라우저 3개 동시 탐색** — A(전문 업체·공식몰), B(쇼핑몰·오픈마켓), C(시공·설치 업체)가 각자 검색해서 업체 1곳씩 고르고(중복 금지) 견적을 모읍니다.
   - 가격이 있으면 숨은 비용(설치·배송·A/S 연장·출장비 등)과 공급자 정보·조건까지 출처와 함께 기록, 원본 화면 캡처 보관
   - 가격이 없으면 견적 요청 메일 카드 또는 견적서 업로드 카드
   - 차단·로그인 화면이면 멈춤 → "확인했어요, 계속" 또는 "다른 업체로 바꾸기"
3. **비교** — 값이 하나씩 확정될 때마다 재정렬되어 "표시가 최저"의 순위가 바뀌는 게 보입니다.
4. **업체별 견적서** — "A 업체 견적서 보기": 전통형 견적서 양식(공급자·견적금액 한글 표기·유효기간/납기/결제조건/인도장소·품목표·공급가액/부가세/합계·특기사항)으로 통일, "원본" 탭에서 웹 캡처·메일·파일 원본 확인.
5. **확인·추천·작성** — 빠진 항목 질문 메일, 추천과 이유, 주문 문의(폼을 제출 직전까지 채우고 멈춤).
6. **통합 견적서** — 업체별 견적을 한 장에: 제품가·설치·배송·A/S·추가 비용·공급가액·부가세·합계·납기·조건·추천. PDF 저장.
7. **견적 히스토리** — 견적은 자동으로 이 컴퓨터에 저장됩니다. 왼쪽 히스토리 탭에서 지난 견적을 누르면 그때의 대화·브라우저 화면·비교표·견적서가 그대로 다시 뜹니다 (보기 전용, "현재 견적으로"로 돌아옴).

## UI

shadcn/ui(Tailwind v4) + [AI Elements](https://ui.shadcn.com/docs/ai-elements)(Conversation, Message, Task, Tool, Shimmer, Loader) · 검정/블루 테마.
AI SDK의 `useChat`은 HTTP 라우트 하나로 채팅 스트림을 주고받는 구조라, Electron main에서 여러 에이전트를 돌리는 이 앱에는 쓰지 않았습니다. Claude 호출은 공식 Anthropic SDK로 합니다.

## 안전 규칙 (코드로 강제)

- 제출·결제·장바구니 버튼 클릭은 도구가 거부하고, 폼은 제출 직전에서 사용자에게 넘깁니다.
  - 예외 하나: 견적서 출력 창이 신청자명만 묻는 경우에만 설정한 이름을 넣고 "다음/확인"을 누릅니다 (누르기 직전에 양식 모양을 다시 확인).
- 메일은 사용자가 버튼을 눌러야만 발송됩니다.
- 사용자 브라우저의 기존 탭은 건드리지 않고, 돌다리가 연 탭만 조작합니다.
- API 키는 main 프로세스에서만 사용합니다.
- Google 계정은 OAuth로 연결하고 비밀번호를 보지 않습니다. 토큰은 main 프로세스에서만 쓰고 OS 키체인으로 암호화해 보관합니다.
