# 돌다리 (팀 빅딜)

사람이 여러 사이트를 돌아다니며 견적을 내 보는 번거로움을 대신하는 **견적 에이전트** 데스크톱 앱.
브라우저 3개가 동시에 업체를 찾아 견적을 모으고, 웹·메일·파일로 제각각인 견적을 **하나의 견적서 양식으로 통일**해 보여 줍니다.

## 실행

```bash
npm install
npm run dev
```

처음 실행하면 설정 창이 열립니다. Anthropic API 키를 넣으면 바로 쓸 수 있습니다 (이 컴퓨터의 `.env`에만, 권한 600으로 저장).
Gmail 주소 + 앱 비밀번호를 넣으면 앱에서 메일을 보내고 업체 회신을 자동으로 읽습니다. 없으면 "메일 앱으로 열기" + "회신 붙여넣기".

## 브라우저

설정(⚙️) → 브라우저에서 고릅니다 (바꾸면 앱 재시작).

- **Aside 우선 (기본)**: Aside 브라우저(`aside` CLI)가 있으면 `aside mcp`로 사용자의 실제 브라우저 탭을 조작합니다. 탭 화면은 카드에 이미지로 보이고, 카드를 클릭·스크롤·타이핑하면 그 탭에 전달됩니다.
- **내장 브라우저**: 앱 안에 보이는 브라우저(WebContentsView)가 카드 자리에 그대로 뜹니다. 사용자가 직접 보고 쓰는 브라우저와 같은 방식이라, 화면을 바로 클릭·입력할 수 있습니다. 카드가 화면 밖으로 스크롤되면 마지막 화면 이미지가 대신 보입니다.
  - **브라우저 로그인**: 설정에서 사이트 주소를 넣고 "브라우저 로그인"을 누르면 같은 세션의 창이 열립니다. 직접 로그인해 두면 내장 브라우저가 그 로그인 상태를 씁니다 (돌다리는 비밀번호를 보지 않음).

에이전트 커서는 페이지에 스크립트를 넣지 않고 앱 레이어에 그립니다. 차단 회피 기법(자동화 흔적 숨기기, CAPTCHA 풀이, 프록시 등)은 쓰지 않습니다.

### 차단 화면 → 사용자에게 넘기기

페이지 이동·클릭 뒤 HTTP 403/418/429, 보안 확인(CAPTCHA) 문구, 원하지 않은 로그인 리다이렉트가 보이면 에이전트가 **바로 멈추고** 카드에 노란 안내를 띄웁니다.
- **해결했어요, 계속**: 사용자가 화면에서 직접 해결한 뒤 누르면 같은 단계부터 이어서 진행
- **건너뛰기**: 그 업체를 빼고 다음 업체를 찾음 (검색 페이지가 막혔으면 다음 검색 엔진으로). 시도할 업체가 없으면 메일/파일 대안 또는 URL 입력 안내

### 업체 URL을 직접 주기

첫 요청에 업체 URL을 넣으면 검색 없이 그 업체들(최대 3곳)에서 바로 견적을 받습니다.

## 테스트용 목업 업체

```bash
npm run mock
```

- `http://localhost:4101` 가격 공개 + 수량 옵션에 따라 금액 계산
- `http://localhost:4102` 가격 비공개, 메일 문의만
- `http://localhost:4103` 첫 방문은 HTTP 418 보안 확인 화면 → "확인"을 누르면 정상 (계속 테스트)
- `http://localhost:4103/always` 항상 418 (건너뛰기 테스트)
- `http://localhost:4104` 가격은 보이지만 배송비·제작 기간은 닫힌 "배송/교환" 탭 안에만 있음 (숨은 정보 탐색 테스트)
- `http://localhost:4105` 1시트(24개) 600원 — 1개 가격으로 잘못 읽으면 다른 업체보다 수십 배 비싸짐 (수량 재확인 테스트)
- `http://localhost:4106` 화면엔 가격이 없고 "견적서 다운로드"를 누르면 가견적서 PDF가 내려옴 (PDF 받기·분석 테스트)

예: "원형 방수 스티커 3000장 견적 비교해 줘. 지름 50mm 유광, 예산 20만원, 10일 안에, 대구 수성구로 택배, 설치·A/S는 필요 없어요. 업체: http://localhost:4101 http://localhost:4102 http://localhost:4103"

## 흐름 (대화 하나로 이어짐)

1. **요구 조건** — 품목을 말하면 수량·예산·납기·설치·A/S·지역을 짧게 묻습니다.
2. **브라우저 3개 동시 탐색** — A(전문 업체·공식몰), B(쇼핑몰·오픈마켓), C(시공·설치 업체)가 각자 검색해서 업체 1곳씩 고르고(중복 금지) 견적을 모읍니다.
   - 가격이 있으면 숨은 비용(설치·배송·A/S 연장·출장비 등)과 공급자 정보·조건까지 출처와 함께 기록, 원본 화면 캡처 보관
   - 가격이 없으면 견적 요청 메일 카드 또는 견적서 업로드 카드
   - 차단·로그인 화면이면 멈춤 → "확인했어요, 계속" 또는 "다른 업체로 바꾸기"
3. **비교** — 값이 하나씩 확정될 때마다 재정렬되어 "표시가 최저"의 순위가 바뀌는 게 보입니다.
4. **업체별 견적서** — "A 업체 견적서 보기": 전통형 견적서 양식(공급자·견적금액 한글 표기·유효기간/납기/결제조건/인도장소·품목표·공급가액/부가세/합계·특기사항)으로 통일, "원본" 탭에서 웹 캡처·메일·파일 원본 확인.
5. **확인·추천·작성** — 빠진 항목 질문 메일, 추천과 이유, 주문 문의(폼을 제출 직전까지 채우고 멈춤).
6. **통합 견적서** — 업체별 견적을 한 장에: 제품가·설치·배송·A/S·추가 비용·공급가액·부가세·합계·납기·조건·추천. PDF 저장.
7. **견적 히스토리** — 견적은 자동으로 이 컴퓨터에 저장됩니다. 왼쪽 히스토리 탭에서 지난 견적을 누르면 그때의 대화·브라우저 화면·비교표·견적서가 그대로 다시 뜹니다 (보기 전용, "현재 견적으로"로 돌아옴).

## UI

shadcn/ui(Tailwind v4) + [AI Elements](https://ui.shadcn.com/docs/ai-elements)(Conversation, Message, Task, Tool, Shimmer, Loader) · 검정/블루 테마.
AI SDK의 `useChat`은 HTTP 라우트 하나로 채팅 스트림을 주고받는 구조라, Electron main에서 여러 에이전트를 돌리는 이 앱에는 쓰지 않았습니다. Claude 호출은 공식 Anthropic SDK로 합니다.

## 안전 규칙 (코드로 강제)

- 제출·결제·장바구니 버튼 클릭은 도구가 거부하고, 폼은 제출 직전에서 사용자에게 넘깁니다.
- 메일은 사용자가 버튼을 눌러야만 발송됩니다.
- 사용자 브라우저의 기존 탭은 건드리지 않고, 돌다리가 연 탭만 조작합니다.
- API 키는 main 프로세스에서만 사용합니다.

## 구조

```
apps/desktop/src
├─ main/
│  ├─ browser/           driver(공통), aside(MCP), electron(앱 안 브라우저 뷰), cursor(앱 레이어 커서), page(검색·본문·차단 감지), index
│  ├─ agent/             Claude tool use 루프, 도구, 프롬프트, 추출 스키마
│  ├─ channels/          메일 발송·수신, 견적서 파일 추출
│  ├─ quote/             정규화, 필드 확정 큐(순위 역전)
│  └─ orchestrator.ts    전체 흐름
├─ shared/               타입, 총액·순위·조건·추천, 통일 견적서(buildDoc)
└─ renderer/             shadcn/ui + AI Elements 대화형 UI, 견적서 문서(doc/)
```
