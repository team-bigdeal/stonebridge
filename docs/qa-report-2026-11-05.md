## 3. 사용성 개선점과 아쉬운 점

**고친 것 (✅)**
- 조사 오류: "75,000원로" → "75,000원으로", "스티커몰는" → "스티커몰은"
- 좁은 창에서 "건너뛰기" 버튼·제안 칩 잘림
- 기록 삭제 확인에 날짜·시간 없음
- 채팅 입력칸 aria-label

**남은 오류 (⏳)**
- 완료된 카드에 "견적 정보 보고 중"이 남아 있음
- 접속이 안 되는 주소를 "사이트에 내용이 없어 탐색 종료"로 안내
- 업체가 하나도 들어오기 전에 "새 견적"으로 취소한 검색은 히스토리에 안 남음
- 품목이 200자를 넘으면 말없이 잘림

**정책 판단 (오류 아님, 결정 필요)**
- 배송비·납기를 모르는 업체가 정보가 다 있는 조금 비싼 업체보다 위에 옴 ("미확정" 표시는 있음)

**잘 되는 것 (🧪)**
- 1280·1600px 넘침 없음
- 이름 없는 버튼 0개, alt 없는 이미지 0개
- 상태를 색이 아니라 글자로도 표시
- 채팅에 HTML을 넣어도 글자로만 표시

**실제 앱 시험에서 통과한 시나리오 (🧪)**

| 시나리오 | 결과 |
|---|---|
| 정상 흐름 (4101·4104·4106) | 75,600 / 75,000 (숨은 탭 배송비 3,500 찾음) / 68,500 (PDF 읽음), 스티커팩토리 추천, 견적서·통합 견적서 열림, 약 3분 |

## 4. 테스트하지 못한 영역과 남은 위험

- **Gmail 연결 상태의 메일 시연** (실제 발송 → 받은편지함 회신): 실제 메일이 나가서 시험하지 않음. 계정 없이 하는 시연 흐름만 🧪 확인.
- **다른 Google 계정 로그인**: 테스트 사용자 등록 필요. kh63167574만 확인.
- **#62 수정 중 앱에서 직접 확인 못 한 것**: 견적서 PDF 저장, 바뀐 CSP에서 앱 안 PDF 보기, 패키징한 dmg 앱의 외부 이동 차단, 멈추기 메시지, 차단 화면 뒤 업체 이름 다시 읽기.
- **화면 배율 80~150% 제한**: 자동 키 입력이 앱 창에 전달되지 않아 확인 못 함.
- **실제 업체 사이트**: 사이트마다 다름. 넓어진 제출 판별 때문에 "가격 계산" 같은 진짜 제출 버튼을 쓰는 오래된 인쇄소 계산기는 메일·핸드오프로 넘어갈 수 있음.
- **#62가 바꾼 동작의 위험**
  - 1000개당 가격을 쓰면서 실제로는 낱개도 파는 사이트는 이제 비싸게 잡힘
  - 새로고침하면 진행 중이던 검색은 멈춤 (히스토리에는 남음)
  - 예산 1,000원 미만·지난 납기는 시작이 막힘
- **네트워크 끊김, API 장애·요금 소진, Windows/Linux, 느린 응답**: 확인 못 함.
